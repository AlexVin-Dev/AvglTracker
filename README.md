**Avgar Line Tracker** — это десктопное приложение для автоматического отслеживания рейсов в Euro Truck Simulator 2 и American Truck Simulator. Оно читает данные телеметрии игры и отправляет информацию о завершённых рейсах на сервер.

## ✨ Возможности
- 📊 Автоматическое распознавание начала и завершения рейса
- 💾 Сохранение рейсов локально и отправка на сервер
- 🎨 Современный тёмный интерфейс в стиле 2026
- 🔔 Оверлейные уведомления прямо в игре
- 🔄 Автоматическое обновление через GitHub Releases

## 📥 Установка
Скачайте последнюю версию установщика со [страницы релизов](https://github.com/AlexVin-Dev/AvglTracker/releases) (файл `Avgar-Line-Tracker-Setup-*.exe`). Запустите его и следуйте инструкциям.

## 🚀 Использование
1. Запустите игру (ETS2 или ATS) с включённой поддержкой телеметрии.
2. Откройте приложение Avgar Line Tracker.
3. Введите ваш никнейм в поле «Имя пользователя» и нажмите «Сохранить».
4. Нажмите «Старт» — приложение начнёт отслеживать рейсы.
5. При взятии и сдаче рейса вы увидите уведомление прямо поверх игры.

## ⚙️ Автоматическое обновление
Приложение само проверяет наличие новых версий на GitHub и предлагает установить их. Всё происходит автоматически — вам не нужно следить за обновлениями.
